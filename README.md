# **cameraDIMS**: Modification of the R CAMERA package for DIMS peaklist analysis
 
> ⚠️ 🚫 [DEPRECATED] This repository is archived but still provided here for traceability in support of the Deep Metabolome Annotation (DMA) of *Daphnia magna* publication.


## Overview

This tool adapts the [CAMERA](https://bioconductor.org/packages/release/bioc/html/CAMERA.html) R package for use with DIMS peaklists, specifically for the DMA project ([https://dma.galaxy.bham.ac.uk/](https://dma.galaxy.bham.ac.uk/)).

For new DIMS data analysis, we recommend using [BEAMSpy](https://github.com/computational-metabolomics/beamspy).
